# Context & Architecture Summary

## Overview
Hangeul Valley is a web-based JavaScript / HTML5 game featuring multiple scenes (Farm, Arcade, Dungeon, Fishing) with UI elements (Shop, Vocab Book, Quiz, Level Select, Fish Album).

## Goal
Upgrade UI/UX to 64-Bit Retro Glassmorphism, integrate pure JS Web Audio API chiptune sound synthesis for game actions, and add micro-animations, lighting, and scene transitions, ensuring `node -c game.js` passes with 0 syntax errors.
